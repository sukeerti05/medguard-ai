# MedGuard AI

## Overview
MedGuard AI is a web-based healthcare management system designed to help users manage medicines, medical records, doctor visits, and hospital visits in one place. The system also provides medicine reminders and follow-up alerts so that users do not miss important schedules.

## Problem Statement
Many patients forget to take medicines on time and often keep prescriptions, scans, and medical records in different places. This makes healthcare management difficult and increases the chance of missing important treatments and follow-up visits.

## Solution
This project provides a centralized digital platform where users can securely store healthcare information, track medicines, manage doctor and hospital visits, and receive timely reminders.

## Features
- User registration and login
- Medicine reminder alerts
- Add and manage prescriptions
- Store medical records and scan reports
- Track doctor visits and hospital visits
- Dashboard with upcoming visits and medicine schedule

## Technologies Used
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Other Tools: Twilio, Email notifications

## How to Run
### Backend
1. Open backend folder
2. Install dependencies:
   npm install
3. Create `.env` file
4. Start backend:
   npm run dev

### Frontend
1. Open frontend folder
2. Install dependencies:
   npm install
3. Start frontend:
   npm run dev
